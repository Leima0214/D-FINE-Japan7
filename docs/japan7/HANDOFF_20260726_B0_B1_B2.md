## 4. 明日唯一的研究任务：B0 错误样本审计（无需 GPU）

明日不要训练新模型。先基于已保存的 B0 预测和本地 Japan7 验证集，建立一个可人工复核的 FP/FN 样本包。这个任务的目标是决定下一个模型干预点，而不是寻找一份好看的图集。

### 输入

- 图像：`F:\deeplearning\Japan7-COCO\images\val`
- 标注：`F:\deeplearning\Japan7-COCO\annotations\instances_val.json`
- B0 预测缓存：`outputs/archives/dfine_japan7_b0_b1_b2_20260726/dfine_japan7_b0_coco_predictions_20260726.json.gz`

### 明日应实现并运行的最小工具

计划新增一个只读分析工具，例如 `tools/audit_japan7_b0_errors.py`。它不修改数据集、不需要 GPU，输出到 Git 忽略的 `outputs/japan7_diagnostics/b0_error_audit_YYYYMMDD/`。

工具必须输出：

1. 每个类别前 15 个高置信度 FP：共最多 105 个样本，保留预测类别、分数、bbox、与最近 GT 的 IoU。
2. 每个类别 15 个 FN：共最多 105 个样本，按 COCO small/medium/large 分层，保留 GT bbox、类别、面积和最近预测。
3. 逐类别 contact sheet 和 `fp_samples.csv`、`fn_samples.csv`。
4. 全量 TP/FP 的分数分布、FN 最近预测的分数与 IoU 分布。
5. 一个待人工填写的字段：`manual_error_type`。

人工标注 FP 时只使用以下类别：

```text
lane_marking
road_seam
repair_trace
shadow
stain_or_water
road_texture
road_edge_or_manhole
vehicle_or_foreground
suspected_unlabeled_damage
duplicate_prediction
other
```

`suspected_unlabeled_damage` 必须单独统计，不得把它与普通背景混在一起。

### 审计后的预注册分流

这些是明日审计开始前冻结的决策条件，不因结果好看而临时修改：

## 5. 只有 BAQS 条件成立时的下一次 GPU 实验

BAQS 的第一版只能是一个因果变量：在未匹配 query 中对最高前景分数的一小组 hard-background queries 施加预算归一化的额外分类约束。保持 matcher、bbox/GIoU/FGL、GO-LSD、骨干和推理结构不变；不加分割分支、不加区域头、不同时测试 top-k、阈值和自适应三种变体。

GPU 顺序：

1. 由于 B0 后改动过 criterion 代码，先用当前提交跑一次 `fgl_edge_weighting: none` 的 current-code B0 60e；它是 Q1 的配对对照，不是新模型。
2. 若 current-code B0 与历史 B0 60e 的 AP50:95 相差超过约 `0.002`，先排查复现性，不运行 Q1。
3. current-code B0 通过后，运行 Q1 1e smoke，再运行 Q1 60e；Q1 只改变 hard-background query 分类项。
4. Q1 只在下列条件同时满足时才可进入 132e：AP50:95 相对 current-code B0 至少 `+0.003`，TIDE background dAP 至少下降 `0.3`，且 AP75 与 AR100 均不下降超过 `0.002`。
5. Q1 60e 不达标即停止；不改 top-k、阈值或损失系数进行补救。

若审计指向 DDE，则先重新制定 DDE 的最小单模块版本和同一套 B0/Q1 式门槛，不得把 DDE 与 BAQS 组合成第一轮实验。
